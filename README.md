# SK Diagnostic

Психологическая диагностика учеников Международной гимназии Сколково. Работает самостоятельно, без NocoBase;
вход и справочник учеников и классов — через SkolStream (пакет [sk-common](https://github.com/aleksioprime/sk-common)).

## Как это работает

1. Администратор назначает психологов (раздел «Психологи»).
2. Психолог выдаёт методику классу — каждый ученик класса получает свою попытку. Ученики, пришедшие
   в класс позже, добавляются кнопкой «Новые ученики класса»; ученика из другого класса можно добавить поиском.
3. Ученик входит через SkolStream, видит диагностику в «Моих диагностиках» и проходит её по одному
   вопросу на экране; ответы сохраняются сразу. Для «Мотивации учения» перед началом он указывает дату
   рождения (её нет в SkolStream, а нормы методики зависят от возраста).
4. После отправки результат считается сразу. Психолог видит таблицу класса, карточку ученика
   с интерпретацией и ответами, выгружает Excel. Ученику результат не показывается.

## Методики

| Код | Методика | Расчёт |
|---|---|---|
| `motivation_learning` | Диагностика мотивации учения и эмоционального отношения к учению (10–16 лет) | `backend/app/scoring/motivation.py` |
| `domiki_emotion_primary` | «Домики» О. А. Ореховой, начальные классы | `backend/app/scoring/domiki.py` |
| `domiki_emotion_middle` | «Домики», 7-е классы (расширенный набор домиков) | `backend/app/scoring/domiki.py` |

Расчёты перенесены из скриптов NocoBase на Python и сверены: все 175 результатов, посчитанных в NocoBase,
и 34 примера, прогнанных через исходные скрипты, совпадают (`backend/tests/test_scoring.py`).
Описание методик — `docs/methods/`.

### Новая методика

Раздел «Методики» доступен администратору:

1. **Загрузить методику из JSON.** Формат показывает кнопка «Вставить пример»; файл текущей методики — «Скачать JSON».
   Вопросы методики, которую уже выдавали классам, заменить нельзя: ответы учеников ссылаются на них.
2. **Написать скрипт расчёта** на странице методики. Скрипт на JavaScript получает переменную `data` (ответы и данные
   ученика, как в панели «Входные данные») и возвращает объект через `return`. Поле `summary` — колонки таблицы класса и
   Excel, остальное видно в карточке ученика. Формат скриптов NocoBase (`return { status, json }`) подходит без изменений.
3. **Проверить** на сгенерированных ответах: результат, колонки и вывод `console.log` обновляются при наборе. Проверка
   ничего не сохраняет. Попытки, завершённые до правки скрипта, пересчитываются в выдаче кнопкой «Пересчитать».

Скрипт выполняется в V8 (`backend/app/scoring/sandbox.py`) без доступа к файлам, сети и окружению приложения,
с ограничением 2 секунды и 128 МБ. У трёх методик из таблицы выше расчёт встроенный: скриптом его заменить нельзя.

Если в результате ошибка (например, нет даты рождения), психолог исправляет дату в карточке ученика
и пересчитывает результат.

## Разработка

```bash
docker compose -p sk-diagnostic up -d --build
```

Приложение — http://localhost:8701, API — http://localhost:8700/api/docs, почта — http://localhost:8704.
Администратор — `admin@example.org`, пароль в `docker-compose.yaml`.

Тесты backend: `cd backend && DB__PORT=8710 REDIS__PORT=8711 pytest -q`.
Фронтенд: `cd frontend && npm ci && npm run lint && npm test && npm run build`.
